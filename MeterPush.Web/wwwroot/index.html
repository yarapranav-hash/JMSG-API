Automatic hourly push

      

        
...

        
        
      

      
When ON, the program pushes the hourly data by itself at 2 minutes past every hour (12:02, 13:02 ...). The 12:02 run takes today's date and the 12:00 readings: only meters whose latest reading is exactly 12:00 are sent, meters already sent for that hour are not sent again. It starts until 29 minutes past if it was busy or the program had just started. It only runs while the program (start-web.bat) is running. Nothing is sent when it is OFF.
